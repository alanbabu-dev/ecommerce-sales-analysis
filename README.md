# E-commerce Sales Data Analysis

## Project Overview
This project analyzes e-commerce sales data to identify sales trends, customer behavior, product performance, and regional performance.

## Objectives
- Analyze total sales and revenue.
- Identify top-performing products.
- Understand monthly sales trends.
- Analyze customer purchasing behavior.
- Compare regional sales performance.

## Tools & Technologies
- Microsoft Excel
- SQL
- Power BI
- Git & GitHub

## Project Structure
- `dataset/raw` – Original datasets
- `dataset/cleaned` – Cleaned datasets
- `excel` – Excel analysis
- `sql` – SQL queries
- `powerbi` – Power BI dashboard
- `images` – Dashboard screenshots
- `docs` – Documentation
